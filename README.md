# Tópicos Avanzados de Programación

Prácticas de la materia en **C++**: algoritmos de búsqueda y ordenamiento, programación orientada a objetos, manejo de archivos, interfaces gráficas con Windows Forms y visión por computadora con OpenCV.

![.NET](https://img.shields.io/badge/Windows_Forms-C++/CLI-512BD4?logo=dotnet&logoColor=white)

## Prácticas

| Carpeta | Tema | Descripción |
|---|---|---|
| [`busquedaOrdenamiento`](busquedaOrdenamiento) | Algoritmos | Menú interactivo con burbuja, selección, inserción, *merge sort* y *quick sort*, búsqueda secuencial y binaria, impresión paso a paso y comparación de complejidad. |
| [`Busqueda`](Busqueda) | Algoritmos | Versión modular de búsqueda y ordenamiento. |
| [`Cambiado a POO`](Cambiado%20a%20POO) | POO | Refactorización del programa anterior a clases. |
| [`DocumentacionDoxy`](DocumentacionDoxy) | Documentación | Código documentado con Doxygen. |
| [`FicherosCSV`](FicherosCSV) | Archivos | Lectura de un CSV de estudiantes, ordenamiento y visualización en ventana. |
| [`PersonaStream`](PersonaStream) | Archivos | Lectura y escritura de registros con `stringstream`. |
| [`PersonasForms`](PersonasForms) | GUI + archivos | Altas y consulta de personas guardadas en archivo de texto. |
| [`Ventanas`](Ventanas) | GUI | Varias ventanas en Windows Forms y procesamiento de imágenes. |
| [`Trabajo OpenCV`](Trabajo%20OpenCV) | Visión por computadora | Captura de cámara en tiempo real, conversión a escala de grises y edición de imágenes. |

## Requisitos

- Visual Studio 2022 con **Desarrollo para el escritorio con C++** y **Compatibilidad con C++/CLI**
- [OpenCV](https://opencv.org/releases/) para la práctica de visión por computadora

Cada carpeta tiene su propia solución `.sln`.
